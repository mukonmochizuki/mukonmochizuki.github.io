Website Standard Operating Procedures (English)

Follow these step-by-step workflows to update your live website.

SCENARIO A: Finished an event (and nothing new to announce yet)

Step 1: Update the Homepage (index.html)

Action: In index.html, scroll down to <h2 class="section-title">Upcoming Events</h2>.
Delete the entire <div class="featured-event-grid"> ... </div> block.
Paste the "Coming Soon" code below in its place. 

<!-- COMING SOON PLACEHOLDER -->
<div style="border: 1px dashed rgba(232, 224, 212, 0.2); background-color: var(--warm-dark); padding: 5rem 2rem; text-align: center; margin-bottom: 2rem;">
  <h3 style="font-size: 1.6rem; font-weight: 300; letter-spacing: 0.1em; color: var(--off-white); margin-bottom: 1rem;">New Performances Coming Soon</h3>
  <p style="color: var(--muted); margin-bottom: 2.5rem; font-size: 1.1rem;">Stay tuned for upcoming event announcements.</p>
  <div class="button-group">
    <a href="events.html" class="card-btn secondary">View Past Events</a>
  </div>
</div>

Step 2: Clean up the Events Page (events.html)

Action: In events.html, look above the "Past Performances" header.
Delete the entire <div class="event-section"> ... </div> that holds the old upcoming event. Leave nothing above the Past Performances header.

Step 3: Add to Past Archive (events.html)

Action: In events.html, find <div class="past-events-grid">.
Paste this thumbnail code right underneath it, so it becomes the newest item in the grid. 

<div class="past-event-thumb" 
     data-img="YOUR_FLYER_IMAGE.jpg" 
     data-title="Full Title Here" 
     data-date="Date Here" 
     data-venue="Venue Name, City" 
     data-role="Your Role Here" 
     data-desc="Description of the event goes here.">
  <img src="YOUR_FLYER_IMAGE.jpg" alt="Thumbnail Alt Text" />
  <div class="thumb-overlay">
    <span>YEAR</span>
    <h4>Short<br>Title</h4>
  </div>
</div>

SCENARIO B: Have a NEW upcoming performance to publicize?

Step 1: Update the Homepage (index.html)

Action: In index.html, scroll down to <h2 class="section-title">Upcoming Events</h2>.
Delete the "Coming Soon" placeholder block.
Paste this Event Grid code in its place and fill in the details. 

<div class="featured-event-grid">
  <img class="event-chirashi" src="YOUR_FLYER_IMAGE.jpg" alt="Event Title" />
  <div class="event-details">
    <span class="event-date">Date Here</span>
    <p class="event-info"><strong>Event Title Here</strong><br>Time Here<br>Location Here</p>
    <div class="button-group">
      <a href="YOUR_TICKET_LINK" target="_blank" rel="noopener" class="card-btn">Get Tickets</a>
      <a href="events.html" class="card-btn secondary">See All Events</a>
    </div>
  </div>
</div>

Step 2: Update the Events Page (events.html)

Action: In events.html, paste this full event section directly above the <h2 class="section-label" id="past-performances">Past Performances</h2> tag. 

<div class="event-section">
  <div class="event-grid">
    <img class="event-chirashi" src="YOUR_FLYER_IMAGE.jpg" alt="Event Flyer" />
    <div class="event-details">
      <span class="event-date">Date Here</span>
      <h3 class="event-title">Event Title Here</h3>
      <div class="event-info">
        <p><strong>Time:</strong> Time Here</p>
        <p><strong>Location:</strong> <a href="MAP_LINK" target="_blank" rel="noopener" style="color: var(--orange-rope); text-decoration: underline; text-underline-offset: 4px;">Location Name</a></p>
        <br>
        <p>Full event description goes here.</p>
      </div>
      <div class="button-group">
        <a href="YOUR_TICKET_LINK" target="_blank" rel="noopener" class="card-btn">Get Tickets</a>
      </div>
    </div>
  </div>
</div>
